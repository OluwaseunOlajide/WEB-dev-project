# Cyber Portfolio
### Standalone Package
 This folder contains the complete source code for a Cyberpunk-themed portfolio website.
 ### How to Run
 Simply open the index.html file in any modern web browser (Chrome, Firefox, Edge, Safari).
 ### Dependencies
 The website uses Content Delivery Networks (CDNs) for its dependencies to keep everything in a single file.
 ### You will need an active internet connection to load:
 <li>Tailwind CSS: For styling.</li>
 <li>Three.js: For the 3D background animation.</li>
 <li>Google Fonts: For the 'Orbitron' and 'Rajdhani' typefaces.</li>
 <li>Images: Placeholder images (RoboHash, Placehold.co) are loaded from the web.CustomizationTo customize the content, open index.html in any text editor (like VS Code, Notepad++, or Sublime Text)</li>
 <li>Profile Image: You can decide to add this if you want </li>
<li>Links: Update href="#" with your actual social media links.</li> 
<li>.Structureindex.html: The core file containing HTML structure, CSS styling, and JavaScript logic (including 3D animations)</li>
<li>API Key: If you want the AI features to work for your visitors, you will need to insert a valid Gemini API key in the script section where it says const API_KEY = "";</li>
